# API Tests

This directory contains HTTP client tests for the Solastra API.

## Files

- **`api-tests.http`**: HTTP client test requests (run in IntelliJ IDEA)
- **`http-client.env.json`**: Environment configuration (auto-generated by `./gradlew deployLocal`)
- **`test-upload.sh`**: Shell script for command-line testing
- **`resources/sample-upload.txt`**: Sample file for upload tests

## Prerequisites

- IntelliJ IDEA (or any JetBrains IDE with HTTP Client plugin) for `.http` files
- LocalStack running (via `./gradlew deployLocal`)
- cURL installed (for shell script tests)

## Running Tests

### Option 1: IntelliJ IDEA HTTP Client

1. Deploy to LocalStack from project root:
   ```bash
   cd ../../..
   ./gradlew deployLocal
   ```

2. Open `api-tests.http` in IntelliJ IDEA

3. Click the green play button (▶) next to any request

4. The `{{baseUrl}}` variable is automatically loaded from `http-client.env.json`

### Option 2: Command Line (cURL)

```bash
# Make script executable (first time only)
chmod +x test-upload.sh

# Run tests (auto-detects API Gateway ID from Terraform)
./test-upload.sh

# Or specify API Gateway ID manually
./test-upload.sh YOUR_API_GATEWAY_ID
```

## Available Endpoints

- **POST** `/upload` - Echo text endpoint (text/plain)
- **POST** `/upload/file` - Upload single file (multipart/form-data)
- **POST** `/upload/files` - Upload multiple files (multipart/form-data)

## Expected Responses

### Single File Upload
```json
{
  "success": true,
  "fileName": "sample-upload.txt",
  "fileSize": 175,
  "contentType": "text/plain",
  "message": "File uploaded successfully"
}
```

### Multiple Files Upload
```json
{
  "success": true,
  "fileCount": 2,
  "totalSize": 350,
  "message": "2 file(s) uploaded successfully"
}
```

### Error Response
```json
{
  "success": false,
  "error": "File is empty"
}
```

## Troubleshooting

### 400 Bad Request
1. Ensure LocalStack is running: `docker ps | grep localstack`
2. Check API Gateway ID in `http-client.env.json` is correct
3. Rebuild and redeploy: `cd ../../.. && ./gradlew deployLocal`
4. Verify multipart configuration in `application.properties`

### View LocalStack Logs
```bash
# Real-time logs
docker logs -f localstack-solastra

# Search for errors
docker logs localstack-solastra 2>&1 | grep -i error

# Search for upload requests
docker logs localstack-solastra 2>&1 | grep upload
```

### Manual cURL Test
```bash
API_ID=$(cd ../../../infra/terraform/localstack && terraform output -raw api_gateway_id)
BASE_URL="http://localhost:4566/restapis/${API_ID}/dev/_user_request_"

# Upload single file
curl -X POST "${BASE_URL}/upload/file" \
  -F "file=@./resources/sample-upload.txt" \
  -v
```

## File Upload Limits

Configured in `api/boot/src/main/resources/application.properties`:
- Maximum file size: 10MB
- Maximum request size: 10MB

To change these limits, update:
```properties
spring.servlet.multipart.max-file-size=10MB
spring.servlet.multipart.max-request-size=10MB
```
